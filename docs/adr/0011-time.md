# ADR-0011 — Injected clock service

- **Status:** accepted
- **Context:** Spec says "inject a clock everywhere so tests can move time".
- **Decision:** `Clock` Protocol with `now() -> datetime`, `today(tz) -> date`, `sleep(seconds)`. FastAPI dependency provides `SystemClock`. Tests override with `FakeClock`. APScheduler jobs receive the same Clock via DI.
- **Consequences:**
  - Late-penalty bands, deadlines, reminders, and audit timestamps are all driven by the injected clock.
  - Daylight-saving boundaries and month-end crossings become unit tests.
  - No test ever calls `time.sleep` for time control.
- **Alternatives considered:**
  - `freezegun` — works but global; would interfere with APScheduler and WebSocket tests.
